# Minipeople Candles — конструктор

## Что уже готово
- Полный интерфейс конструктора: выбор контейнера, цвета, отделки, аромата (с описанием), фитиля — для свечи
- Отдельная короткая ветка для подсвечника: цвет + аромат
- Экран сводки заказа и контактов
- Заготовка серверной функции `api/create-order.js` для будущей оплаты через ЮKassa

## Что предстоит подключить (следующий этап)
- Реальный вызов ЮKassa API внутри `api/create-order.js`
- Вебхук от ЮKassa на подтверждение оплаты
- Сохранение заказов в Supabase
- Уведомления в Telegram о новом заказе
- Выбор ПВЗ Яндекс Доставки на экране контактов

## Как опубликовать (шаг за шагом)

1. Загрузи содержимое этой папки в новый репозиторий на GitHub
   (на github.com: New repository → Upload files → перетащи все файлы и папки)
2. Зайди на vercel.com → New Project → выбери этот репозиторий → Deploy
3. Через 30–60 секунд Vercel даст ссылку вида `https://имя-проекта.vercel.app`
   — открой её, чтобы проверить, что конструктор работает
4. Дальше эту ссылку нужно будет подключить к Telegram-боту как Mini App
   через @BotFather → /mybots → Bot Settings → Menu Button

## Как редактировать товары, цвета и ароматы
Все данные лежат в начале файла `public/index.html`, в блоке
`/* ======================= ДАННЫЕ КАТАЛОГА ======================= */`.
Меняешь текст, цены, hex-коды цветов — сохраняешь файл — публикуешь заново
через GitHub (Vercel подхватит изменения автоматически за секунды).
